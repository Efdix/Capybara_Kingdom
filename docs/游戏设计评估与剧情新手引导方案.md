## 〇、总评

**系统密度已经是一款完成度很高的幸存者游戏；但它的灵魂——一份生日礼物的
情感叙事——只在最后 30 秒出现，而玩家真正的第一分钟（战斗）恰好是全游戏
唯一没有引导的地方。**

| 维度 | 分 | 一句话 |
|---|---|---|
| 核心循环 | 9 | 战斗→种子→种植→材料→蛋糕双腿走路；软失败、零卡关，承诺兑现彻底 |
| 战斗手感 | 8 | 顿帧、受击闪白、死亡炸裂、呼吸相位、步频随速度——细节超同类 |
| 成长经济 | 7.5 | 卡池+融合+技能树+集市闭环自洽；印记 15/20 缺口是有意设计 |
| 双人协作 | 8 | 真联机权威结算、大招不对称、合击有约 |
| 叙事情感 | **3** | 无序章、无对白、无过程叙事；结局情感是空降的 |
| 新手引导 | **4** | 种地链优秀；战斗/升级/大招/兽潮/决斗全部裸奔 |
| 内容量 | 7 | 15 怪 11 种 AI、5 霸主、20 卡；通关后偏薄但可接受 |
| 工程品质 | 9.5 | 自动验收 ROM、资源校验、字体自动扫描、帧预算测量 |

后续所有建议都建立在一条前提上：**本作的差异化卖点不是「又一个幸存者」，
而是「一件会被两个人一起玩、并记住的生日礼物」。** 一切优先级以此为轴。

## 一、问题清单（按严重度）

### ★★★ P0：影响核心体验

**1. 开场零叙事，情感回报没有铺垫**
游戏全部叙事资产 = 五行地区风味字 + 霸主名牌卡 + 结局两行「生日快乐」。
玩家从头到尾不知道「为什么捡种子、为什么烤蛋糕」，直到结局才被告知这是个
生日——对普通游戏这只是遗憾，对生日礼物这是最大浪费：**它把唯一的情感
爆发点交给了毫无铺垫的 30 秒**。（`main.c:1121-1151` 之前不存在任何叙事状态）

**2. 战斗第一分钟零教学，而它恰好是全游戏最反直觉的一分钟**
幸生者类「没有攻击键」对没玩过这个品类的玩家是强烈反直觉——第一次进图的
玩家几乎一定会狂按 A 试图攻击，然后在困惑里死掉或摸不着头脑。当前战斗内
唯一教学是大招 HUD 一行常驻小字（`game.c:7748`）。引导链七步全部在主城，
教的却是循环的**后半段**（种地），而不是前半段（战斗）。

**3. 决斗零教学 + 决斗失败的隐性重罚**
决斗操作体系完全切换（A 跳 / B 翻滚无敌帧 / 前摇解读），首次进入没有任何
说明。更重的是失败惩罚：每次进图 `g_seed_have` 清零（`game.c:5474`），决斗
败北意味着重新刷满召唤计量——火山 45 颗种子约 10 分钟纯重复。「死亡无惩罚」
的承诺在霸主战上出现了一个沉默的例外。

### ★★ P1：结构性缺口

**4. 无撤退机制**
远征只有两个出口：打死霸主，或者死（`ST_PLAY` 无暂停/撤退，B 是技能键）。
「死亡无惩罚」在数值上补了这个洞，但体验上「我想回家种地」和「我被围死」
是两种完全不同的情绪——后者还附送一张失败画面。玩家会学会一件怪事：
**想回家的时候，去找死。**

**5. 无暂停菜单、无操作说明页**
设置只有音量两项（`main.c:1312-1350`）；战斗中调音量必须死一次回标题。
生日当天第一次拿 NDS 的人（很可能就是寿星）没有任何地方能查「这游戏怎么按」。

**6. 过程叙事缺位：进度没有可感知的回应**
通关结算是纯数字（击退数/蛋糕进度，`main.c:957-993`）；主城对「集齐一份
材料」没有任何视觉变化。蛋糕账只活在下屏清单里，王国不为它亮一盏灯。

**7. 结局演出与全游戏投入不匹配**
静态画面 + 两行淡入字 + 名单。作为整个情感设计的终点，它现在是全项目
「系统复杂度 / 演出投入」比值最低的一块。同时「她」的名字与日期只在标题
一闪，专属感埋得浅。

### ★ P2：打磨级

**8.** 首次升级三选一无引导（暂停 + 三张卡第一次出现时玩家是懵的）。
**9.** 大招首次充满只有 HUD 小字；双人 40 帧连放触发「水豚合击」没有任何
提示，全靠偶然发现——这是双人游戏最值得教的一件事。
**10.** 首场兽潮 50 秒准时砸脸（`WAVE_FIRST 3000`），无预警。
**11.** 引导文案用绝对方位词（「出征之门在北边」），对没有地图习惯的新手
不如用地标锚（「最高的那座门」）。
**12.** 田鼠偷种子偷的是召唤计量（`game.c:4526-4528`），首次发生时玩家
只看到数字变小，不知道发生了什么、也不知道追杀能拿回双倍。

### 必须保留的设计哲学（改的时候别碰）

- 教学链「一次一句、永不阻塞、老档永久静默」（tutorial.c 文件头宣言）——
  下文所有新增引导全部继承这条。
- 软失败 + 材料永不丢——「两人一起玩永远不会卡关」是本作的底层承诺。
- 主城刻意小——它是节奏呼吸，不是第二个战场。
- 字体自动扫描源码——**加台词零美术成本**，这是本项目做叙事的独特优势。

## 二、剧情设计：「把甜味还给王国」

### 三条设计决策

1. **零新增玩法**。所有叙事挂点都长在既有系统上（种子/材料/霸主/蛋糕/结局），
   不给生日当天的玩家增加任何学习成本。
2. **主题统一到水豚的天性：安抚**。卡池里「安抚」「感化」是水豚真实性格做成的
   机制，母水豚大招叫「温柔庇护」——那么叙事上，霸主就不是被「打死」的，
   是被「安抚」的。结局它们来赴宴。这一条把战斗、卡牌、结局缝成同一主题。
3. **「生日」保密到最后一刻**。全程只说「重要的日子」，蛋糕出炉、蜡烛点亮，
   游戏才第一次对玩家说「生日快乐」。悬念成本为零（现有流程本来就是这么走的），
   只是终于有人把它**说**出来了。

### 序章（3 屏，仅无存档首次出现，任意键翻页，B 直接跳过）

新增状态 `ST_INTRO`，在「开始游戏 → 选角」之后、进主城之前；有存档的标题
流程完全不经过它。上屏像素画（可复用 gen_world 的场景件），下屏文字
（`text_panel` 已有，注释里就写着 "Used for dialogue boxes"）。

> **第 1 屏 · 湿地的清晨**
> 水豚王国有一座老烤箱。
> 它烤过王国所有的节日：庆典的、丰收的、雨季结束的。
> 但今年，烤箱冷了。
>
> **第 2 屏 · 老面包师的话**
> 「五位霸主把甜味都带走了。」
> 老面包师叹气，「树精抱走了水果，鼠王囤起了面粉，
> 黑牛占着牧场，鳄王守着甘蔗，火山里那位……
> 连『生日』这个词都不许人说。」
>
> **第 3 屏 · 出发**
> 「重要的日子快到了。去把它们请回来吧——
> 不用打倒它们，水豚最擅长的，是陪着谁，等它消气。」
> 卡和皮对看一眼，跳进了水里。
> （操作提示一行：方向键移动 · 水豚自己会战斗）

### 五霸主人设与「安抚台词」

每位霸主的领地逻辑与现有场景美术（芭蕉/麦田/牧草/甘蔗/可可）一一对应。
安抚台词在**通关结算画面**以一行金句出现（挂在 `level_clear_screen` 现有
「拿到了种子！」标签下方）：

| 地区 | 霸主的愤怒 | 安抚后的一句话（结算画面） |
|---|---|---|
| 雨林·树精长老 | 睡了三百年被兽潮吵醒，把果子全收进怀里怕被糟蹋 | 「这颗果子……本来，也是想留给谁的。」 |
| 农场·硕鼠大王 | 囤麦不是贪，是「守着仓库就不会饿」的不安 | 「原来分出去的麦子，会变成香味回来。」 |
| 牧场·狂暴黑牛 | 不是狂暴，是把所有靠近的都当成了狼 | 「你们……不是狼啊。」 |
| 沼泽·凯门鳄王 | 最爱死亡翻滚，可沼泽里没有陪它翻的伙伴 | 「下次……还来陪我翻滚吗？」 |
| 火山·蛋糕魔王 | 最孤独的一个：从没被人祝过生日，于是偷走了「生日」 | 「生日……是什么味道的？」 |

先锋出场播报（已有 toast，`game.c:5616`）统一改措辞为「尚未消气的 X」，
与主题咬合：先锋是霸主的怒气分身，不是另一个 boss。

### 主城的回应：蛋糕台（环境叙事）

烤箱旁加一座**蛋糕底座**贴图（做法与菜地地块完全同构：gen_world 加几块
tile、hub 布局落一个点位）。每集齐一份材料，底座上长出一层蛋糕/一根蜡烛
模型——**走到广场就能看见今晚的蛋糕正在一点点成型**。下屏蛋糕清单保留，
但从「账本」降级为「对账用的备注」。这是全方案里性价比最高的一笔：
进度从抽象数字变成抬头可见的实物，且完全复用现有 tile 管线。

老面包师作为烤箱旁的常驻 NPC（一个静态小立绘 + 光环交互）：按 A 一句话，
按进度查表（序章刚结束/每安抚一位/集齐后各一句，共 8 句左右）。不需要
对话系统，单句查表即可。

### 结局强化

现有演出保留（烟花、蛋糕、蜡烛、两只水豚），追加两件事：

1. **五位霸主小小地入席**：画面下沿站五个缩小的霸主剪影，蛋糕魔王离蛋糕
   最近——它被安抚的那句「生日……是什么味道的？」在这里得到回答：
   蜡烛为它**多点一根**。
2. **名单后的献词屏**：复用标题已有的她的名字/日期，单独一屏、居中、
   停 5 秒或按键翻页。这一屏才是这件礼物的落款。

结局文案本身（「生日快乐！」「谢谢你们陪我一起冒险」）不动——它是对的，
问题从来不是结尾这句线，而是前面一小时没有人替它铺路。

## 三、新手引导设计

### 四条原则

1. **继承现有哲学**：一次一句、事件驱动、永不阻塞、老档静默。
2. **战斗教学用 toast**（`show_toast` 现成），**主城教学用提示行**（现有），
   **决斗教学用一次性说明卡**——唯一例外，因为决斗是一整套新操作，
   一行说不清，静态卡是合理代价。
3. **进度全存档**：`g_tut_flags` 是 u16，已用 7 位，剩余 9 位直接扩展，
   旧档高位为 0 = 未教，天然向后兼容（save.c:45 布局不用动）。
4. **教在行为发生的那一刻**：玩家掉第一滴血、捡第一颗种子、攒满第一次
   大招——时机由事件定义，不由计时器定义。

### 战斗 toast 链（新增 6 个位）

| 新位 | 触发事件 | 文案 |
|---|---|---|
| TUT_B_MOVE | 首次进任意地区 90 帧后 | 「水豚自己会咬——你只管走到怪物边上」 |
| TUT_B_HURT | 本地水豚首次掉血 | 「往怪少的地方走；红心能补回来」 |
| TUT_B_LEVEL | 首次升级暂停时（卡片界面顶部加一行，非 toast） | 「三选一，选一张立刻生效——没选的以后还会出现」 |
| TUT_B_ULT | 大招首次充满 | 「大招满了！按 R 释放」+ 大招按钮闪 3 秒 |
| TUT_B_COMBO | 联机时双方大招同时满 | 「两人接连释放，就是水豚合击」 |
| TUT_B_WAVE | 首场兽潮开始前 300 帧 | 「兽潮要来了：往开阔地走，金冠怪必掉种子」 |

另有两个零成本补丁：田鼠首次偷种子时 toast「田鼠偷走了召唤进度！追上它，
拿回双倍」；首次精英入屏时 toast「金冠怪：必掉种子，值得一博」。

### 决斗说明卡（新增 1 个位）

霸主跃出清场、切入横板的过场（现名牌卡 `game.c:5807` 那块屏）之后插入
一张约 220 帧的静态卡，任意键开始：

> **决斗**
> A 跳跃（轻点小跳，长按大跳）
> B 翻滚（无敌帧，空中还能用一次）
> 看前摇再动：红线 = 冲锋 · 落点圈 = 砸落 · 爆圈 = 别贴脸
> 血量 66% / 33% 会变招加速
> ——按 A 开始

仅首次出现（1 个 flag），第二次进决斗自动跳过。

### 主城链改良（不动结构，只改两句 + 加一个箭头）

- 方位词换地标锚：「出征之门在北边」→「沿栈道过桥，最高的那座门」；
  「东南的温泉」→「冒着热气的那池水」。
- 首日复用战斗的**红色边缘箭头**（现成系统）指向当前引导目标地标，
  该步完成箭头即消失——方位问题用空间指示解决，不用文字解决。
- 温泉步骤补半句「（远征回来也会自动过夜）」，防止玩家以为必须手动睡。

### 暂停菜单 + 操作说明页（补最大的结构性缺口）

`ST_PLAY` 加 START 暂停：单人直接冻结世界；联机时世界继续、只弹本机面板
（面板首行注明「联机中世界不会暂停」）。面板三项：

```
继续
操作说明    ← 一页写全野战 + 决斗两套按键（README 的表格搬进来）
音量        ← 复用 settings 现有逻辑
```

暂停菜单里加第四项「**回王国**」——这就是撤退机制的答案：明亮的、
主动的、不附带失败画面的离场。种子照带走，与死亡同权，但情绪完全不同。

### 决斗失败修正（引导之外，但它摧毁引导建立的一切信任）

决斗败北后，世界地图上该地区显示「**霸主仍在等你们**」，选择后**直接再战**
（不重刷召唤计量）。种子已在账上付过一次，第二次不该再收一遍钱。
顺带把 `level_clear_screen` 与 GAME_OVER 画面措辞统一成「安抚未成」而非
失败语汇。
