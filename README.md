# 水豚生存 · 生日蛋糕大冒险

Capybara Survival — 一台 NDS + 一台 3DS 用烧录卡一起玩的本地联机双人**幸存者类**游戏。

两位主角本身就是两个汉字：角色 1 是**「卡」**，角色 2 是**「皮」**。
他们在远大于屏幕的地图里顶住越来越强的兽潮，**捡回种子**；
种子带回王国的菜地种下去，长出五种蛋糕材料；集齐五份材料就能烤出蛋糕。

用 [BlocksDS](https://blocksds.skylyrac.net/) 开发，纯 C，全部美术、音乐、中文字体
都由本项目脚本程序化生成。

> **美术管线说明（宝可梦重制后）**
> 本轮美术整体向 GBA 宝可梦（宝石版）的画法看齐，规则收敛为四条，由
> `gen_common.py` 的共享画具强制执行：**Q版比例**（头是全身最宽的形状，
> 头身分界清晰）、**大眼睛**（`pk_eye`：白眼球 + 大瞳孔 + 左上/右下双高光，
> 太小的脸自动退化为单点珠眼）、**硬边双面光**（`pk_shade_bottom` 底部暗面 +
> `pk_rim` 左上受光边，不用抖动渐变）、**近黑冷描边**包住凸面轮廓。
> 25 只生物（15 杂兵 + 10 霸主）与双主角全部按这套语言重画：霸主仍以
> 64×64 起稿、八种姿态，杂兵四帧是真实动作形变；主角 128 帧（8 向 × 16）
> 带眨眼、六帧步态、露门牙的咬合与冒汗受击，额头汉字印改用深毛色点阵
> （浅毛色的「皮」不再是黑窟窿），「皮」耳边多了一朵经变色映射变粉的小花。
> 六个地区地图同步重制：地面是纯色底 + 疏密不均的硬边草痕与「宝可梦草丛
> 三撇」，树冠是带波浪轮廓的一大团三色球，水波是短亮划（不再带暗色回笔），
> 民居是奶油墙 + 蓝框白十字窗 + 陶瓦/青瓦双屋顶。`tools/ascii_view.py`
> 可以把任何生成的像素画转成明暗字符画，无图形界面也能肉眼审稿。

> **当前是「玩法优先」阶段。**
> 敌人用的是 `graphics/mob_tiles.bin` 里的像素画，同一套图按各自的
> `MonsterDef.scale` 缩放绘制，所以体型差异是看得见的。
> 更早的一批怪物 / Boss 美术收在 `art_retired/` 里，不参与构建。

## 玩法要点（当前版本）

| 部分 | 说明 |
| --- | --- |
| 主角 | 汉字「卡」「皮」作底的水豚，八个方向、每个方向 16 帧 |
| 主城 | 48×40 格 ＝ 768×640 像素的**湿地公园**，六处地标密集分布在环湖步道旁 |
| 选关 | 从城门进入**远征地图**，五个地区是地图上五个不同位置的节点 |
| 地区 | 128×96 格 ＝ 2048×1536 像素，等于 8×8 个屏幕，镜头跟随主角 |
| 敌人 | 15 种怪物分属 11 种 AI 行为：蛇形蜂群、抛物线树蛙、死亡分裂软泥、偷材料的田鼠、俯冲乌鸦、脉冲泥怪、群猎野犬、冲锋黑羊、鼓舞牛虻、喷吐毒蟒、自爆火球（其中四组两两共用同一种行为，靠体型、血量与速度区分） |
| 精英 | 金冠精英怪：2.5 倍血、5 倍经验、必掉种子、常掉红心，兽潮期间大量出现 |
| 兽潮 | 开局 50 秒后第一场，之后每 70 秒一场 10 秒**兽潮**：刷怪翻倍、精英频出，挺过去有战利品 |
| 决斗 | 材料集齐后霸主**跃出清场**，进入横板 1v1 决斗：跑动、跳跃、翻滚无敌帧 |
| 大招 | 杀敌攒进度，R 键或点下屏释放；公母效果不同，双人可合击 |
| 等级 | 打怪得经验，**连击加成**最高 +40%，升级时**游戏暂停**并弹出三张**卡片** |
| 选卡 | 下屏可以直接**触屏点击**卡片，也可以用十字键 / L / R 移动 + A 确定 |
| 种田 | 打怪掉**种子**，回主城在**菜地**播种、浇水，睡一觉就长大；成熟后收获蛋糕材料 |
| 存档 | 技能树、印记、菜地、蛋糕账、天数、音量**和引导进度**会**写进卡带存档区**，第二天开机还在 |

主城有意做得小：它是两局之间走一圈的地方，不是第二个战场。
六处地标都在广场周围几步路以内，全部靠木板栈道连起来。

小地图在战斗界面右下角，能看出地形轮廓、主角位置和首领位置；
首领不在视野内时，屏幕边缘会出现一支红色箭头指向它的方向。

血量、等级与经验条显示在**上屏**顶部的一条状态栏里，下屏留给小地图、
卡牌列表、收集进度和五个触控按钮（四个技能格 + 大招）。

### 主城里的六处地标

| 方位 | 地标 | 作用 |
|------|------|------|
| 北 | 出征之门 | 打开**远征地图**，选择关卡 |
| 西北 | 信鸽塔 | 无线联机（主机 / 客机） |
| 东北 | 神树 | 被动技能树 |
| 南 | 蛋糕烤箱 | 材料集齐后烤蛋糕、看结局 |
| 西南 | 集市 | **材料换印记**：任意 5 份材料换 1 枚霸主印记，溢出材料不再是废物 |
| 东南 | 温泉 | **按 A 歇一晚**：浇过水的作物长大一阶，天数 +1 |
| 西 | **菜地** | 24 块耕地：播种 / 浇水 / 收获（走近按 A，不是地标，没有菜单） |

走到地标旁，地上会亮起一圈光环、地标上方浮起一个光点，下屏同步显示提示，
这时按 A 进入。

### 剧情与新手引导

**序章（只演一次）**：第一次玩，选完角色和模式会先看三页故事——王国的老烤箱
冷了，五位霸主把甜味都带走了，火山里那位连「生日」这个词都不许人说。老面包师
说：「不用打倒它们，水豚最擅长的，是陪着谁，等它消气。」任意键翻页，B 直接
跳过；老档永远不会再看到它。

**引导链（一次一句，永不阻塞）**：开局有一条事件驱动的引导链，它只在主城提示
条上占一行字，每完成一步自动说下一步，进度写进存档——老玩家永远看不到它。
它覆盖两段路：

- **主城七步**：出征之门 → 捡种子 → 播种 → 浇水 → 温泉睡觉 → 收获 → 烤箱。
  提示按「地标长相」指路（「最高的那座门」「冒着热气的温泉」），同时主城里
  会出现一支**金色箭头**从屏幕边缘指向当前目标（就是野战里指霸主的那支箭头，
  换了个颜色），走到就消失。
- **野战八课**：在事件发生的那一刻才说——进图 90 帧后教「水豚自己会战斗」、
  第一次掉血教走位、第一次升级在选卡界面教规则、大招第一次攒满教 R 键、
  联机双人攒满教合击、首场兽潮前 5 秒预警、田鼠第一次行窃教追杀、第一次
  见到金冠精英教掉落。全部只在每个存档里出现一次。

**决斗说明卡（仅首次）**：霸主清场跃出后，第一场决斗开始前有一张静态说明卡：
A 跳跃、B 翻滚（无敌帧）、看前摇再动、66%/33% 变招。按 A 开始；之后的决斗
直接开打。

**暂停与撤退**：野战里按 **START** 弹出暂停面板：继续 / 操作说明 / 音量 /
**回王国**。单人暂停会冻结世界；联机中世界继续走、只弹面板（撤退一项在联机
中不可用）。「回王国」是堂堂正正的离场——种子照带回去，和打赢回来是同一种
回家，没有失败画面。

**决斗再战**：决斗败北不算清零——世界地图上该地区会亮起「**霸主候场**」，
再选它**直接再战**，不用重新刷满召唤计量（种子在账上已经付过一次了）。败北
画面会告诉你哪只霸主还在等你们。重启主机后此记录清空，需要重新召唤。

**结算与结局**：每只霸主消气时会说一句自己的台词（雨林的「果子……本来也想
留给谁的」、火山的「生日……是什么味道的？」）。结局烟花下，**消过气的霸主
会来赴宴**——一排小小的身影坐在草坪上；给蛋糕魔王多点的那根金色蜡烛，只有
它来赴宴时才会点亮。制作名单滚完还有一屏献词。

### 远征地图（选关）

每个地区节点下面有一排小点，表示**这个地区的危险档位**（越靠后的地区，难度时钟起步越高），
选中的地区还会在横幅上显示「危险 ★★」和「推荐下一站」或「难度偏高」。
**这只是提示，不是门槛**——五个地区从开局就都开着，因为「打不过就换个地方先攒种子」
是这局游戏承诺过的退路。

出门后是一张羊皮纸风格的手绘地图，五个地区分布在岛上不同位置：
雨林在西南、农场在西北、牧场在东北、沼泽在中南、可可火山在东南，
中央是水豚王国的城堡。十字键 / 左右在五个节点之间移动，A 出发，B 回城；
已通关的地区会打上对勾。上屏是地图本身，下屏是所选地区的详情
（出产材料、先锋首领、最终首领）。触屏也可以直接点下屏的五个地区按钮。

## 一、构建 ROM

在 **MSYS2 的非登录 shell** 里执行。这点很重要：登录 shell 会把 `TMP` 指向
`C:\WINDOWS\`，编译器无法创建临时文件，会报 `Error 127`。

```bash
# 从 Windows 的 Git Bash 或 CMD 调用：
D:\Life\msys64\usr\bin\bash.exe -c "cd /d/System/Documents/GitHub/Capybara_Kingdom && ./build.sh"
```

或者用 MSYS2 的 bash 进入项目目录后：

```bash
./build.sh              # 构建正式 ROM -> capybara_kingdom.nds
./build.sh clean        # 清理

# 以下是开发用的自演示 ROM：游戏会按脚本自动按键 / 触摸，
# 方便在模拟器里逐屏截图验证，正式 ROM 里不包含这些代码。
./build.sh --autoplay   # 自动跑战斗流程
./build.sh --menu       # 自动升级，验证升级选卡界面
./build.sh --tap        # 同上，但用触屏点击选卡（验证触摸路径）
./build.sh --boss       # 自动打到首领出现，验证首领战
./build.sh --farm       # 走到菜地：播种、浇水、睡一晚、看作物长大
./build.sh --ending     # 直接进入结局演出
./build.sh --perf       # 自动跑战斗，把掉帧计数画在上屏（见下）
```

`build.sh` 已处理好全部环境变量（`BLOCKSDS`、工具链 PATH、`TMP`），无需额外配置。
生成的 `capybara_kingdom.nds` 可以直接拷进烧录卡。

> **注意**：ROM 图标必须是 **32×32、最多 15 色**的 GIF。
> DS 的横幅图标只允许 16 个调色板项，其中 1 个被 ndstool 留作透明色，
> 所以美术本身只能用 15 色。超了的话 ndstool **不会报错**，只会打一行警告
> 然后写出一个头部全空、无法启动的 ROM。`gen_icon.py` 会自动量化到 15 色并校验，
> `verify_assets.py` 也会检查成品 ROM 的头部，防止这类问题流到真机上。

### 构建流程

```
tools/gen_*.py          生成美术/字体/音频        -> graphics/ audio/
                        （gen_world 出地块与地图、gen_ui 出标题与世界地图、
                          gen_farm 出菜地贴图、gen_font 会扫描源码里用到的每个汉字）
tools/gen_farm.py       菜地贴图：土壤干/湿 + 5 作物 × 3 阶段
tools/verify_assets.py  资源完整性检查（180 项）   尺寸、调色板、缺字、菜地落点、卡面张数、静音
bin2c                   把二进制资源转成 C 数组
mmutil                  把 11 首 MOD（每地区一首战斗曲）+ 16 个音效打成 soundbank
arm-none-eabi-gcc + ndstool                    -> capybara_kingdom.nds
```

资源校验会在每次构建时自动执行；若某个资源损坏（尺寸不符、字体缺字、
音频静音），构建会直接失败而不是产出一个有问题的 ROM。

## 二、在两台真机上联机玩

两台机器都插烧录卡，都直接引导 `capybara_kingdom.nds`。**不需要路由器、
不需要 WiFi、不需要联网** —— 用的是 DS 自带的任天堂本地无线，
和官方 DS 游戏面对面联机是同一套机制。

1. **主机**（NDS 或 3DS 都行）：标题画面选「开始游戏」→ 选角色
   → 选「创建派对（联机主机）」→ 屏幕显示「等待另一位勇者加入」
2. **客机**：同样标题 → 选角色 → 选「加入派对（联机客机）」→ 自动搜索到房间并连上
3. 两边都进入王国广场后，选一个秘境就可以一起出发

联机是**真双人**：野战里客机的攻击、受击、升级、大招都由主机权威结算后
同步回来；霸主印记是两人共享的钱袋（客机买技能、换印记都会上报主机入账），
菜地在哪台机器上耕都是同一块地。任何一方断线（约 3 秒收不到对方），
双方都会收到明确提示：主机原地继续单人，客机退回王国，绝不会留下一个
凭空冻结的队友。

选角自动分配：先选的人操控自己挑的那只，另一台自动拿剩下的一只，
所以一局永远是一公一母、两个大招都在场。

### 关于 DLDI 补丁

本游戏**不访问文件系统**（全部资源都编译进 ROM），所以绝大多数烧录卡
**不需要**打 DLDI 补丁，拷进去直接玩。个别老烧录卡若提示需要补丁，
Makefile 里有现成的 `dldipatch` 目标可用。

### 3DS 注意事项

3DS 玩 NDS 烧录卡是以 **DS 兼容模式**运行的，这正是联机需要的模式，
所以 NDS 和 3DS 之间可以直接互联，3DS 侧不需要任何额外设置。

### 联机不上怎么办

- 两台机器靠近一些（本地无线有效距离约 10 米内，中间别有厚墙）
- 客机若搜不到，回到模式选择重新选一次「加入派对」
- 游戏底屏会显示当前连接状态（「单人模式」/「联机:主机」/「联机:客机」），
  可以据此判断是否连上
- 无论如何**单人模式始终可玩**，一人推完全部流程没问题

## 三、在模拟器里试玩

```bash
D:\Life\melonDS\melonDS.exe D:\System\Documents\GitHub\Capybara_Kingdom\capybara_kingdom.nds
```

项目自带一套自动验证工具（定位模拟器画面、注入按键、按屏截图，无需人工操作）：

```bash
# 逐屏截图（自动把窗口调成 2 倍整尺度，输出 256x192 的上/下屏 PNG）
python tools/melonds_capture.py --out .shots --name title --zoom 3

# 注入按键（自动把模拟器窗口调到前台再发送）
python tools/melonds_play.py --keys down,down,x --wait 500
```

**注意**：截图工具要求 melonDS 开启整数缩放（`melonDS.toml` 里
`IntegerScaling = true`），否则它量出的画面尺寸不是 256x192 的整数倍，
裁剪会错位。旧脚本 `melonds_drive.ps1` / `melonds_grab.ps1` 仍保留，
但 melonDS 1.1 会忽略外部注入的按键，请用上面两个 Python 工具。

**存档与模拟器**：melonDS 1.1 探测不到本作的存档芯片（EEPROM），而游戏
为此准备的「先写一次再读回验证」自适应流程，在 melonDS 未解析存档类型时
会让模拟的总线传输永不完成，ARM9 就地死等——因此**自演示 ROM（--autoplay
等）编译时不带这条回退路径**，在模拟器里按「无存档芯片」规则完整可玩；
正式 ROM 保留该流程（真机烧录卡总线必有应答，不受影响）。若想在模拟器里
测存档，请换用新版 melonDS 或在配置里手动指定存档类型。

melonDS 也能模拟本地联机（开两个实例，`Config > Multiplayer`），但官方文档
指出它对本作使用的 CMD/REPLY 封包**模拟并不完美**，所以联机手感请以两台真机为准。

### 逐屏验收（`--ui` 自演示 ROM）

`./build.sh --ui` 会编译一个把全部菜单界面自动走一遍的自演示 ROM：设置 →
选角 → 模式 → 主城 → 技能树 → 联机大厅 → 远征地图 → 战斗 → 结算 →
失败 → 结局 → 制作名单。配上截图工具即可无人值守地逐屏验收 UI：

```bash
./build.sh --ui && python tools/melonds_capture.py --name ui
```

跳转到结局 / 结算 / 失败画面的调试按键（`START` / `L` / `R`）只存在于
`--ui` 自演示 ROM 里，正式 ROM 不包含。

### 帧预算（`--perf` 自演示 ROM）

`./build.sh --perf` 编译一个把**掉帧计数**画在上屏的自演示 ROM：它统计「游戏自己走完 60 帧的
同时，显示器产生了多少次 VBlank」。理想值是 60——每一帧都落在一次刷新里；一旦某帧的绘制
超时，它就会吃掉两次刷新，这个数字就往上跑。

在 melonDS 上跑满一场雨林战斗（同屏五六只怪、连击、飘字全开）实测：

```
late/60  0      ← 最近 60 帧里没有一帧超时
worst    0      ← 整个会话至今没有任何一帧超时
```

也就是**渲染离帧预算还有余量**，所以这一版没有改用 DMA：在 ARM9 上做 DMA 拷贝前必须先
把 48 KB 的影子缓冲刷出 cache，那笔开销会把 DMA 省下来的时间抵消掉大半，而测量结果并不支持
这笔交易。这个读数留下来是为了以后：真机上的表现请以真机为准，melonDS 不会精确模拟
VRAM 的等待周期。

> 顺带记一笔踩过的坑：这块**计时器不要用**。DS 的定时器是两个 CPU 共用的，链接了 dswifi 和
> maxmod 之后 ARM7 固件已经把四个都占了（声音通道用 0 和 1，dswifi 用最后一个），从 ARM9 读
> 出来的计数会在半路被重置。用 VBlank 中断去数也没用——没有配套的应答处理时中断会反复重入，
> 游戏会直接卡成幻灯片。最后用的是 `REG_IF` 的 VBlank 标志位：libnds 的 `swiWaitForVBlank()`
> 就是轮询这一位实现的，所以等待之前读一次，就知道上一帧有没有跨过整个刷新。

## 四、玩法

### 操作

| 按键 | 野战 | **霸主决斗** |
|------|------|------|
| 方向键 | 移动（战斗全自动，玩家只负责走位） | 左右跑动 |
| A | 释放 A 键位技能 | **跳跃**（可控制高度） |
| B / L | 释放 B 键位技能 | **翻滚**（带无敌帧，空中可用一次） |
| X / Y | 释放对应键位技能 | 释放前两个技能格 |
| **R** | 释放**大招**（攒满后可用） | 释放大招 |
| **START** | **暂停面板**（继续 / 操作说明 / 音量 / 回王国） | — |
| 触屏 | 技能格 / 大招按钮 | 跳跃 / 翻滚大按钮 + 技能格 |

决斗是**横板单挑**：场景从俯视切成侧面竞技场，杂兵全部退场，只能用野战里
攒下的卡牌、水球和已充能的大招对决霸主。霸主的每次攻击都有明显的**前摇
提示**（冲锋画红线、砸落画落点、近身爆圈），66% / 33% 血量会**转阶段**加速。
**踉跄之后霸主有 10 秒破势免疫**：打出一跪、爆发、躲它站起来的反扑，
再攒下一跪——节奏是「破势、爆发、应答」，而不是无限锁死。

### 霸主决斗的五个对手

| 地区 | 霸主 | 招式风格 |
|------|------|----------|
| 雨林 | 树精长老 | 慢而重，根须弹幕+砸地冲击波，惩罚贴脸 |
| 农场 | 硕鼠大王 | 快速连冲+三连射，节奏最碎 |
| 牧场 | 狂暴黑牛 | 超长冲锋+重接触伤害，冲击波要跳 |
| 沼泽 | 凯门鳄王 | 宽幅水弹+死亡翻滚，贴身会被爆圈弹开 |
| 火山 | 蛋糕魔王 | 全部招式加速版，最终考试 |

幸存者类游戏没有攻击键：水豚会自己咬、自己放技能，玩家的操作就是**移动**——
把水豚拉到不会被围死的地方，同时尽量从兽群边上蹭过经验点。

### 大招

杀敌攒进度条（每只杂兵 1 点、首领 8 点，满 28 点），攒满后按 **R** 或点下屏
右侧的按钮释放。**决斗里杂兵稀少**，所以充能另算：每 1.5 秒自动 +1、
每次被霸主命中 +2，一场战斗大约能攒出一次释放——它是 Boss 战的底牌，
不是永远灰着的按钮。两只水豚的大招不一样：

| 角色 | 大招 | 效果 |
|------|------|------|
| 阿棕（公） | 怒涛冲击 | 一圈冲击波扫倒身边所有敌人 |
| 阿奶（母） | 温柔庇护 | 回满血、安抚全场杂兵、吸走所有掉落 |

两人联机时，如果两只水豚在 40 帧内先后释放，第二次会触发**组合大招「水豚合击」**：
冲击波加强、安抚时间延长，并把范围内的敌人全部击晕。

进度对两只水豚同步累积——任何一只杀敌，两人一起涨，所以组合技是可以约好的，
不是碰运气。

### 主循环

游戏现在有**两条腿**：出门打仗捡种子，回家种地收材料。

**远征**：从王国广场选一个地区 → 在兽潮里杀怪捡**种子**（开局 50 秒后第一场**兽潮**，之后每 70 秒一场，
精英出没，必掉种子）→ 种子过半时**先锋**在野外出场，击败可得一批种子
→ 攒满种子后**霸主一跃而出**，小怪清场、掉落尽收 → 切入**横板决斗场** 1v1
→ 打倒霸主 → 回王国挑战下一个地区。

**种地**：回到王国走到西南的**菜地** → 按 A 在站的那块地上播种
→ 按 B 一次性给整片地浇水 → 去**温泉**按 A 睡一晚（或在远征回来后自动过夜）
→ 浇过水的作物长大一阶，两天后成熟 → 按 A 收获，材料进蛋糕账。

集齐五份材料（水果/面粉/牛奶/糖/巧克力各自有额定量）后回王国按 Y
或走到烤箱按 A，就能烤出蛋糕、看到结局。

**为什么材料不在怪身上了**：上一版里「打怪掉材料」其实是唯一的经济来源，
于是战斗和进度是同一条线——打不过就没进度，打赢了就只是继续打。
现在怪掉的是种子，材料要自己种出来，于是每一段远征都在为下一步投资，
而种田的节奏（浇水、过夜）把「什么时候出发」也变成了一个决定。

**一局是没有时限的**：怪会随时间越来越强、越来越密（每 27.5 秒升一档，
最高 12 档，后开的地区起步档位更高）。被打到没血不是游戏结束，而是这一局
结束——**捡到的种子和已经收到的材料都不会丢**，可以回去重来，
甚至可以去别的地区先攒种子。这样两个人一起玩永远不会卡关。

### 存档

游戏把**跨局的东西**写进卡带的存档区：被动技能树的四支等级、霸主印记、

菜地每一块地的状态、五种种子存量、天数、已通关的地区、以及两项音量设置。

写盘时机是每一个会改变这些数字的动作——播种、浇水、过夜、买到技能、通关一个地区、

调音量——所以不需要「记得存档」这件事。

**不存的是这一局本身**：等级、卡牌、血量和位置。死掉仍然只是这一趟远征结束，

不掉任何已经到手的东西，回到城里继续种地。

存档用的是卡带自带的存档芯片（和正版 DS 游戏同一套机制），所以**不需要 DLDI 补丁**，

拷进烧录卡就能用。标题画面下方会直接写明存档状态：

「存档：已记录」/「存档：空」/「存档：此卡带无存档芯片」——

没有存档芯片时游戏照常玩完整个流程，只是不跨天。

### 菜地

王国西南的一块地，**6×4 = 24 块** 耕地，画在地图上的草坪里，不是菜单。

| 操作 | 效果 |
|------|------|
| 走近菜地，按 **A** | 脚下那块地：空地就播种，干了就浇水，熟了就是**收获** |
| 走近菜地，按 **B** | 给整片地浇水。24 次单独浇水只是重复劳动，没有决策 |
| 温泉按 **A** | 过一晚：浇过水的作物长大一阶，土壤重新变干，天数 +1 |
| 打完一场远征回城 | 也自动过一晚。打完首领的人不会记得再去睡一觉 |

- **种子按地区分五种**，和五种材料一一对应（雨林掉水果种子，农场掉面粉种子……），
  一个编号贯穿「哪只怪掉什么 / 种出什么 / 换哪种材料」整条链。
- **只有浇过水才会长**：一晚只长一阶，两晚成熟。这是让菜地变成日常、
  而不是装饰的那条规则。
- **一块成熟的地收 3 份材料**。五区的额定量是 12/15/18/21/24，
  也就是 4/5/6/7/8 次收获——一片种满的地一到两轮就能供上。
- 土壤干湿、作物三个阶段都画在**地块贴图**里（`graphics/farm_tiles.bin`），
  成熟的地会闪一圈金边，从广场就能一眼看出来哪块该收了。
- 菜地在**下屏**有一块面板：天数、可收块数、已种块数、五种种子各剩多少。
  走近菜地时它替换掉「蛋糕食材」清单；走开就又换回来。

### 五个地区

每个地区的场景都和当地材料对得上：

| 地区 | 场景 | 出产的蛋糕材料 | 首领 |
|------|------|----------------|------|
| 雨林 | 热带雨林、芭蕉和藤蔓 | 水果 | 树精长老 |
| 农场 | 金色麦田、风车和稻草人 | 面粉 | 硕鼠大王 |
| 牧场 | 高山牧草、栅栏和奶牛 | 牛奶 | 狂暴黑牛 |
| 沼泽 | 甘蔗丛、泥潭和木栈道 | 糖 | 凯门鳄王 |
| 可可火山 | 火山土上的可可树 | 巧克力 | 蛋糕魔王 |

每个地区出一份蛋糕材料，也出**对应的种子**：在这里打的怪掉本地区的种子，
带回王国的菜地种下去，长出来的就是这里的材料。

### 卡牌系统

卡池按水豚**真正会做的事**组织，共 **20 张**：12 张基础卡 + 8 张融合卡。基础卡每张 5 级，
**5 级会变成质变形态**；两张基础卡都到 2 级，升级界面就会多出一个金色的融合选项
（合成会吃掉这两张卡、把较高等级继承给结果，所以它是一次真正的取舍）。
融合卡在**野战和决斗都有完整形态**——每次按下都会把两张父卡的行为
叠加在一起，再加一层自己的增量：

- **物理**：尖牙（自动咬最近的敌人）、铁尾（甩尾扫开一圈）、
  冲撞（朝敌人冲刺，撞飞一路上所有目标）
- **魔法**：水柱（穿透的水枪）、泥沼（留下减速的泥地）、
  粪球（抛出后炸成臭云）
- **辅助**：安抚（让附近敌人失去战意）、感化（转化敌人为同伴，帮你打）
- **被动**：厚皮（加血）、快腿（加速）、磁吸（拾取范围）、利爪（加伤害）

两张辅助卡是水豚在现实里的真实性格做成的机制——它是所有动物都愿意挨着待着的那种动物，
所以「安抚」让敌人不想打你，「感化」满级后甚至能把敌人拉进你这边。

每次升级会**暂停**并给出三张卡选择，每张卡都写清楚它现在是什么、
下一级是什么、以及 5 级终极形态是什么，不用猜。

### 战斗与成长

**连击**：2.5 秒内连续击杀会攒连击数，每级 +2% 经验、20 级封顶（+40%）。
顶着兽潮往人堆里冲是「高风险高收益」，风筝苟活则吃不到加成——这是给
进攻型玩家的奖励，也是屏幕右上角那块金色「连击 x N」的意义。

**掉落**：经验珠（按怪物价值分大小）、**种子**（**每种怪有独立掉落率**——
重型是种子电池，小快怪几乎不掉，先打哪群直接决定菜地能种多快）、
**红心**（重型怪低概率掉、精英常掉、先锋必掉，是升级之间唯一的续航）、
霸主印记（首领掉，解锁被动神树）。满血时捡到红心会折算成经验，不浪费。

掉的是种子，不是材料：材料要靠回城的菜地种出来，详见前面的「菜地」。

**精英怪**：金冠+金圈，2.5 倍血、5 倍经验、**必掉种子**。兽潮期间精英大量出现，
是每场兽潮真正的目标。

**经验曲线**：首级只要两三只小怪，之后每级 +30%+12，一小时的完整流程
大约落在 18~22 级、20 次选卡——够把几张卡点满、剩下的看取舍。

怪物随**时间**变强（难度每 27.5 秒升一档、最高 12 档，后开地区起步更高），
不随玩家等级，所以拖久了不会变简单。每只怪的血量以自身基础值为准再乘上
难度，因此重型怪对小型怪的血量优势全程保持。

### 手感

这一版在「打中」这件事上补了几笔，都是不动物数值的：

- **顿帧（hitstop）**：命中时整个世界停 2~9 帧，越重的打击停得越久（霸主踉跄停得最久）。
  实现方式是把这一帧的状态处理整段跳过——所有画面都画进同一对影子缓冲，不重画就等于
  上一帧原样留在屏幕上，所以冻结是免费的。冻结期间按下的键会被**暂存**，在下一次真正
  执行的那帧补上，不会吞掉输入（暂存做在 `input.c` 里，所以战斗、决斗、菜单全部受益）。
- **受击闪白**：被打中的怪物和主角会有 2~3 帧变成亮色剪影。8bpp 下每个精灵共用一份调色板、
  也没有 alpha，所以「闪一下」只能靠替换像素本身——剪影比染色更省事，而这个长度人眼读到
  的是轮廓而不是内部细节。
- **命中星芒**：伤害数字之外的命中反馈画成四角星芒（两根交叉亮条 + 对角刻线随时间拉开），
  第一帧整圈白闪——在四十只怪的战场上一眼分清「打中了」和「擦过了」。
- **弹道有了自己的视觉语言**：水柱是带渐细拖尾和侧喷水珠的射流；粪球翻滚着飞（高光随
  旋转滚动、身后掉渣）；敌方弹幕按**地区配色**上色（与决斗场同一套 `DuelDef` 颜色），
  沼泽的毒液和火山的火弹一眼可分；树蛙的燃烧弹有了弹体、烟迹和**落点阴影**——顺带修掉
  了一个老 bug：野战里这类抛射弹（以及大招泥块）此前根本没有绘制分支，玩家会被
  看不见的子弹打死。
- **死亡反馈**：怪物不再原地消失，而是留一下「炸开」的痕迹——一圈按体型扩开的环、飞散的
  灰烬和几块往下掉的碎块，精英和霸主的痕迹更大更久。**主角倒下也有了一拍**：世界定格约一秒，
  爆散和震屏先演完，结算画面才到来。
- **斜向移动归一化**：斜走以前比直走快 41%。现在以 1/√2 步长、按 1/256 像素累积亚像素
  余数推进，斜走速度和直走严格一致，且没有取整带来的顿挫。
- **击退是速度不是传送**：被打中的推离改为一段 4~6 帧的衰减速度，叠加在玩家自己的走位上，
  被撞会「滑出去」而不是「闪现过去」。受击硬直也从 16 帧减到 10 帧。
- **决斗输入缓冲**：跳跃、翻滚都带 7~8 帧输入缓冲——落地前一瞬按的跳会在落地那一帧起跳，
  翻滚冷却结束的瞬间按过的翻滚会立刻生效；翻滚方向优先跟随当前按着的方向键，不再是
  死板的「面朝哪滚哪」。
- **镜头前瞻**：镜头向移动方向轻微超前约半块地，走进的空间就是屏幕中间的空间。
- **怪物绘制按纵深排序**：同类怪物重叠时不再因对象池槽位变化而前后闪烁。
- **前摇全部可见**：黑羊/火灵的蓄力冲锋在落点画一个渐收的红色瞄准环加冲刺连线，乌鸦的
  俯冲同样有落点环，泥怪的膨胀爆圈会把身体真实地吹大并套上脉冲红圈——「看到鼓气就后撤」
  从一句攻略变成了屏幕上真的画出来的东西。
- **低血量警示**：血量低于 1/4 时整个屏幕边缘开始脉冲红框，最后一颗心时频率更快、颜色更亮。
- **呼吸不同步**：怪物的待机动作以前读的是同一个全局帧计数，所以满屏 40 只会在同一拍
  一起换姿势；现在每只怪有自己的相位。
- **动画跟着速度走**：走路的步频由**走过的距离**决定而不是帧数，所以加速之后不会滑步；
  站着不动时也会呼吸（以前待机帧只有移动时才会推进）。

### 地板

六个地区的地面整体重做（`tools/gen_world.py`）：

- 地块上的花纹不再用公式定位、不再是同心圆环——旧版每个地块都印着同一个小环和两簇
  高对比草丛，铺满一屏就是一面图案墙。现在所有记号按变体种子随机撒，八个变体里
  有近裸的也有偏密的，平铺出来是疏密不均的**地面**而不是重复的**图案**。
- 地图上的次级地面（泥地、湿土、暗草）改成少数几个**大块有机色斑**，替代原来 90 个
  四到十三格的小碎斑——大色斑读作「晒干的土地」和「树荫」，小碎斑只读作噪点。
- 花与高草从「320 个均匀散布的单点」改为**成簇生长**（一丛一丛的），沼泽与火山的
  次级地面色调也调亮了一档，避免近黑色的泥地吞掉画在其上的一切。

### 天气

六个地区以前只有配色不同，空气都是静止的。现在每个地区有自己的空气：
雨林飘落叶、农场扬麦壳、牧场浮种絮、沼泽冒沼气、火山升余烬，王城落几点花瓣。
它们是几十个按索引哈希定位的像素点，不占状态、不参与存档、两台机器不需要同步
——位置由「第几个点」和帧号算出来，所以两边算出来必然一样。

### 十五种怪物，十五种打法

- **雨林**：飞蜂蛇形逼近（别用瞄准技硬打）、树蛙抛射落地留灼烧地带、
  软泥死后裂成两只小的（先杀大的）
- **农场**：田鼠**偷走你的材料就跑**，追杀它能拿回双份；乌鸦锁定直线俯冲
  （横移躲）；泥怪近身膨胀后放冲击环（看到鼓气就后撤）
- **牧场**：野犬越扎堆越快（先拆散再打）、黑羊蓄力长冲锋（撞完有硬直，
  是输出窗口）、牛虻给同伴加速（**优先击杀的「军鼓」**）
- **沼泽**：毒蟒站定三连吐（吐的时候上去打）、泥蟾双发抛射、
  淤泥怪同软泥会分裂
- **火山**：火灵蓄力穿身冲、蝠翼蛇形高速、火球飘近后**自爆**——
  它自爆没有掉落也没有经验，让它炸到更是血亏，先手干掉它

### 中文显示

游戏里的中文是本项目自制的像素字体（`tools/gen_font.py` 从系统黑体渲染，
阈值化成 1bpp 后打进 ROM）。字体生成时会**自动扫描 `source/` 下所有源码里的
中文字符**，所以新增台词不会出现缺字方框；若有遗漏，
`verify_assets.py` 会直接报出缺了哪些字。

### 想改点什么

- **改祝福语 / 剧情**：`source/main.c` 搜「生日快乐」。改完直接 `./build.sh`
  （字体会自动扫描源码补上新字，缺字会直接让构建失败）。
- **改她的名字 / 日期**：`source/main.c` 的标题画面与 `ST_CREDITS` 分支。
- **改卡池**：`source/globals.c` 的 `g_card_defs` 是全部 20 张卡的数值与文案，
  卡牌的实际效果在 `source/game.c` 的 `fire_card()` 里。
  卡面图案在 `tools/gen_cards.py`（每张卡一个 `em_*` 函数），
  生成后看 `graphics/preview_cards.png`。
- **调难度**：`source/game.h` 的 `DIFFICULTY_STEP` / `SPAWN_BASE` / `SPAWN_MIN`
  控制难度攀升速度和刷怪间隔，`source/game.c` 的 `spawn_monster()` 是怪物成长公式。
- **调决斗**：五霸主血量写在 `source/game.c` 的 `g_duel_defs` 末列，
  `tools/boss_balance_check.py` 的规则 7 会校验「血量落在 45~150 秒（按 25 DPS
  估算）的体验带内」——改完跑一遍它，别让第三阶段还没演完就结束。踉跄的
  破势/免疫参数在 `source/game.h` 的 `STAGGER_*`。
- **调成长节奏**：`source/game.c` 的 `hero_gain_exp()` 里那行经验曲线决定一局能升多少级。
  现在的 `+18% +10` 是按「一个完整流程大约 20 次选卡」反推的——想每次升级来得更快就调小它。
  卡牌机制在哪一级解锁由 `source/game.h` 的 `CARD_UNLOCK_LEVEL` 决定（它同时也是融合门槛）。
- **调技能树**：`source/skill_tree.c` 的 `branch_cost()` 一支树三级各要几枚印记。
  现在是 1/1/3，四支共 20 枚，而一次性通关全图给 15 枚——刚好差一个满级分支。
- **调手感**：`source/game.h` 的 `HITSTOP_*` 是各种打击的顿帧长度，`source/game.c` 的
  `weather_draw()` 表里是每个地区的天气密度与速度。击退力度与硬直在 `hero_take_damage()`
  的中段（`kb_*` 一组字段），决斗的跳跃/翻滚缓冲帧数在 `hero_update()` 的决斗分支里。
- **改地板**：`tools/gen_world.py` 的 `ground_tile()` 是全部六个地区共用的地块画笔
  （花纹密度、草叶、石子都在里面）；`build_map()` 开头两组 `scatter_blob` 控制大块
  次级色斑的数量与半径，`REGIONS` 表里每个地区的 `ground` / `ground2` 三元组是
  (底色, 亮斑, 暗斑) 的调色选择。改完跑一遍脚本看 `graphics/preview_world.png`。
- **调伤害**：怪物的 `damage` 现在是真扣血的（`HERO_MAX_DAMAGE_PER_HIT` 封顶 2 心），
  远程弹幕统一按 `RANGED_CHIP_DAMAGE` 算 1 心。改 `source/sprites.c` 的怪物表就能调
  近战威胁，不会连带影响弹幕。
- **改地图大小 / 地形密度**：`tools/gen_world.py` 顶部的
  `WORLD_COLS` / `WORLD_ROWS`，以及 `build_map()` 里各步骤的数量。
  改完重新生成即可，`source/game.h` 与 `verify_assets.py` 里的同名常量要一起改。
- **改地区与材料**：`source/globals.c` 的 `g_regions`（场景、材料、首领、
  召唤首领所需数量），场景配色在 `tools/gen_world.py` 的 `REGIONS` 表。
- **改菜地**：三处，改完重新生成即可。
  - **落点**：`source/farm.h` 的 `FARM_TILE_X/Y` 决定菜地在王国的哪块草坪上；
    `verify_assets.py` 会读这个头文件、再读生成出来的 `area_hub_map.bin`，
    如果那块地里有实心瓦片（水池、房子）构建就会失败并指出。改了落点记得
    同步那行注释里的坐标。
  - **大小与产量**：同文件的 `FARM_COLS/ROWS`、`FARM_YIELD`、
    `CAKE_NEED_0..4`（五区各自需要的材料数）。
  - **造型**：`tools/gen_farm.py` 里每样作物一个 `crop_*` 函数，土壤在
    `soil()`。跑一遍脚本看 `graphics/preview_farm.png` 就能肉眼确认。
    注意土壤**别画成横向亮/暗条纹**：王国的木栈道就是那个画法，两者会混。
- **改美术**：`tools/gen_*.py` 里的形状参数；运行生成脚本后会在
  `graphics/` 下输出 `preview_*.png` 预览图，方便肉眼确认效果。
